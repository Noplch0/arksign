# 森空岛自动签到工具

这是一个基于 Go 语言编写的轻量化命令行工具，旨在为玩家提供**明日方舟**及**明日方舟：终末地**的自动每日签到服务。

------

## 🚀 核心特性

- **多游戏支持**：同时支持《明日方舟》与《明日方舟：终末地》。
- **定时任务**：内置定时执行器，支持指定时间点自动运行。
- **零依赖运行**：编译后的二进制文件不依赖任何外部环境，开箱即用。

------

## 🛠️ 快速开始

### 1. 首次配置

下载对应系统的执行文件并放入独立文件夹中，运行以下命令添加账号：

```
# 进入程序目录
# <file>为你的程序名，可随意更改
./<file> -a
```

按照终端提示输入账号、密码即可完成绑定。

### 2. 运行方式

程序支持一次性运行或持久化后台运行：

- **立即执行一次**：

  ```
  ./<file> -o
  ```

- **定时执行（推荐）**：

  ```
  ./<file> -t 04:30
  ```

  *注：若不指定时间，默认将在每日 04:30 自动签到。*

------

## 📖 命令行参数详解

| **参数** | **说明**                                 | **示例**                 |
| -------- | ---------------------------------------- | ------------------------ |
| `-a`     | **Add**：进入账号交互式添加流程          | `./<file> -a`       |
| `-o`     | **Once**：立即执行所有账号的签到并退出   | `./<file> -o`       |
| `-t`     | **Time**：设定每日自动签到的时刻 (HH:MM) | `./<file> -t 08:00` |
